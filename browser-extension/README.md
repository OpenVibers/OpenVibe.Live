# Moved: the kiosk companion extension

The OpenVibe Kiosk companion (Firefox new-tab page and history bridge for `/kiosk`) now lives in
[OpenVibe.Extensions `kiosk-companion/`](https://github.com/OpenVibers/OpenVibe.Extensions/tree/main/kiosk-companion),
the home of OpenVibe's first-party client surfaces (ADR-023). It moved unchanged; its history before
the move is in this repository's git log under `browser-extension/openvibe-kiosk-companion/`.
